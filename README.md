# Spirit-Filled Creations Website

Beautiful pastel + velvety emerald green website for selling handmade paintings, key chains & fridge magnets.

Inspired by **Exodus 35:31**.

## Features
- Live animated emerald green background
- Soft pastel colours (mint, blush, lavender, peach)
- Everything centered
- Beautiful scenery images
- Shop with filters
- Exodus 35:31 prominently featured
- Contact form + order modal
- Fully mobile friendly

## How to use
1. Unzip the folder
2. Open `index.html` in your browser to preview
3. Replace WhatsApp number, email and Instagram in `index.html` and `js/script.js`
4. Upload the whole folder to Netlify, Vercel or GitHub Pages

## Hosting (easiest)
Go to https://netlify.com → drag & drop this folder → your site is live!
